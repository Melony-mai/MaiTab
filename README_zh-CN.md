---

**MaiTab** 是一款严格基于 **Manifest V3** 构建的轻量级、零依赖 Google Chrome 浏览器扩展。它通过拦截网页链接的左键点击，在不打断当前页面阅读与浏览体验的前提下，自动将链接在后台或前台新标签页中打开。扩展采用正统的 **macOS Aqua / 苹果系统设置** 视觉规范，支持**明亮模式**、**暗色模式**与**跟随系统外观实时切换**；内置最高优先级的**完整跳过列表（静默列表）**、可灵活配置的**全局焦点开关**、具备子域名自适应匹配且支持独立单网站焦点的**自动切换白名单**、**GitHub 远程仓库直接迭代与弹窗一键同步**功能，并提供针对**英语**、**简体中文**与**日语**的完整国际化多语言支持。

## 核心特性

1. **完整跳过列表（静默列表 / Complete Bypass List）**
   - 允许用户指定需要让 MaiTab **完全停用**的特定网站。
   - **最高绝对优先级：** 完整跳过列表严格优先于其他所有扩展设置。只要当前访问网站匹配跳过列表，扩展将完全不干预其链接点击行为，无论全局焦点开关或白名单如何配置。
   - **保留浏览器原生行为：** 网站上的所有链接与交互组件均严格按照浏览器原生机制运行（支持单页应用路由、当前标签页跳转或网站自定义的 `target="_blank"`）。
   - **零干扰与事件监听完全注销：** 在已跳过的网站上直接注销所有鼠标事件监听器（`mousedown`、`mousemove`、`mouseup`、`click`），消除多余事件捕获与性能开销，确保对复杂 Web 应用零干扰。
   - **独立管理维护：** 在弹窗与选项页中与常规白名单分栏独立管理，互不干扰。
   - **域名自适应与持久化存储：** 通过 `chrome.storage.sync`（带本地回退）可靠持久化，并自动涵盖所有二级及多级子域名（例如跳过 `google.com` 会自动作用于 `mail.google.com` 与 `docs.google.com`）。

2. **左键点击默认在新标签页打开**
   - 在已启用的网站上，左键点击网页超链接将自动在新标签页中打开目标网址，不离开当前正在阅读的页面。
   - 模拟中键点击效果，适合在社交媒体、资讯聚合流、长篇文章、搜索引擎与技术文档中进行连续流畅的无缝阅读。
   - 自动绑定父标签页关系（`openerTabId`）并将新标签页紧邻当前标签页创建（`index: activeIndex + 1`），关闭新标签页时 Chrome 会平滑返回原页面。
   - 智能识别并过滤非页面导航行为：
     - 修饰键（`Ctrl`、`Cmd`、`Shift`、`Alt`）正常触发浏览器原生快捷功能。
     - 鼠标右键与滚轮中键交由浏览器原生处理。
     - 页内锚点跳转（如 `href="#comments"`）在当前页平滑定位，不会打开多余空白标签页。
     - 表单控件（`<button>`、`<input>`、`<textarea>`、`<select>`）、可编辑区域（`contenteditable`）以及带 `download` 属性的文件下载链接均保持正常交互。
     - 实时追踪鼠标拖拽轨迹与文字划选状态，避免在复制链接内部文本时误触打开新标签页。

3. **全局焦点开关（全局自动切换）**
   - 集中控制未列入白名单的普通网站在点击链接时，是否自动将浏览焦点切换到新打开的标签页。
   - **开启（ON）：** 左键点击链接时，新标签页将在前台打开并立即获得浏览器焦点。
   - **关闭（OFF，默认）：** 链接在后台静默打开，保持当前页面阅读不被打断。
   - 弹窗和选项页中均提供直观的切换开关与清晰说明。
   - 通过 `chrome.storage.sync`（自动回退至 `chrome.storage.local`）持久保存。

4. **分网站独立自动聚焦白名单**
   - 允许为白名单中的每个网站单独配置**独立的自动聚焦选项**。
   - **完全独立于全局开关：** 每个网站的独立焦点配置均严格优先于全局焦点开关，赋予特定域名极致定制自由：
     - **开启自动聚焦（前台切换）：** 在该网站上点击链接打开新标签页时立即切换焦点，即便全局开关处于 OFF 状态。
     - **关闭自动聚焦（后台打开）：** 在该网站上点击链接始终在后台静默打开，即便全局开关处于 ON 状态。
   - **智能子域名涵盖匹配：** 白名单添加 `example.com` 即可自动涵盖 `news.example.com` 和 `sub.example.com`，同时杜绝误匹配 `fakeexample.com` 或 `example.com.evil.org`。
   - **即时生效与持久化：** 修改规则即刻生效无需刷新页面，跨浏览器重启持久保留。
   - **一键快捷添加与弹窗内联动：** 弹窗自动感知当前活动标签页的域名，提供快捷的“+ 白名单”/“已在白名单”按钮，并展示内联焦点切换选项。

5. **全流程多语言支持（i18n）**
   - 提供针对**英语（en）**、**简体中文（zh-CN）**与**日语（ja）**的完整本地化翻译。
   - 覆盖所有用户界面：弹窗标签栏、选项页、按钮、状态徽标、详细说明、气泡提示、错误提示、确认对话框与浮动提示（Toast）。
   - 弹窗与选项页均内置语言选择器，支持实时无缝切语言，无需刷新页面或重启扩展。
   - 语言偏好自动保存；完全符合 Chrome 扩展 MV3 本地化标准（`_locales/en`、`_locales/zh_CN`、`_locales/ja`）。

6. **交互式域名匹配测试器与配置导入导出**
   - 高级设置页面提供交互式域名测试工具，可任意输入网址或域名，实时演算并展示其匹配的规则（完整跳过、白名单或普通网站）以及最终的标签页打开与焦点行为。
   - 支持将自动切换白名单与完整跳过列表以标准 JSON 格式导出备份或跨设备导入恢复。

7. **手动检查更新与弹窗同步**
   - **醒目的检查按钮：** 位于弹窗顶栏版本徽标旁，随时可点击检测 GitHub 远程最新状态。
   - **准确的状态提示：** 比对本地与 GitHub 仓库提交信息，准确报告**已是最新**、**有可用更新**、**检查中**或**更新失败**。
   - **安全暂存与冲突保护：** 同步过程自动暂存本地工作，保留未提交修改，若遇冲突则安全暂停并输出排查指引，绝不覆盖本地代码。
   - **弹窗内一键就地同步：** 检测到更新后直接在弹窗内点击“立即更新”，即可通过本地同步服务自动拉取合并。

8. **跟随系统外观的明亮与暗色模式**
   - **三种可选模式：** 支持**跟随系统（自动）**、**明亮模式**与**暗色模式**。
   - **实时系统同步：** 处于“跟随系统”时，毫秒级自适应操作系统深浅色设置变化（`prefers-color-scheme`）。
   - **严格的手动模式优先级：** 手动指定明亮或暗色模式后，设置被锁定并持久生效，直到再次切回“跟随系统”。
   - **全界面一致性：** 弹窗页面与高级选项页面外观始终统一。

## 行为决策矩阵与设置优先级

MaiTab 遵循严格、清晰且可预测的四级优先级架构来决定每个链接点击的最终处理逻辑：

```text
[ 第一级：扩展主开关（Master Switch） ]
                    │
           扩展是否处于启用状态？
            ├── 否  ──> 浏览器原生链接跳转（扩展暂停拦截）
            └── 是
                 │
[ 第二级：完整跳过列表（静默列表 / Complete Bypass List） ]
                 │
        当前网站是否匹配完整跳过列表？
         ├── 是  ──> 浏览器原生行为（扩展完全停用，事件监听器彻底注销）
         └── 否
              │
[ 第三级：分网站白名单独立焦点设置（Whitelist Overrides） ]
              │
     当前网站是否匹配自动切换白名单？
      ├── 是  ──> 遵从该网站在白名单中的独立焦点设置（优先于全局开关）
      │            ├── 自动聚焦开启  ──> 前台新标签页（立即切换焦点）
      │            └── 自动聚焦关闭  ──> 后台新标签页（保持当前页面）
      └── 否
           │
[ 第四级：全局焦点开关（Global Focus Toggle） ]
           ├── 开启（ON）  ──> 前台新标签页（立即切换焦点）
           └── 关闭（OFF） ──> 后台新标签页（保持当前页面，默认状态）
```

### 优先级决策对照表

| 完整跳过列表匹配 | 白名单匹配 | 该网站独立聚焦设置 | 全局焦点开关 | 最终链接与标签页行为 |
| :---: | :---: | :---: | :---: | :--- |
| **匹配** | 任意 | 任意 | 任意 | **浏览器原生行为（扩展彻底停用，注销监听）** |
| 未匹配 | **匹配** | **开启（聚焦）** | 任意（ON 或 OFF） | **前台新标签页**（立即切换焦点；白名单优先） |
| 未匹配 | **匹配** | **关闭（后台）** | 任意（ON 或 OFF） | **后台新标签页**（保持当前页面活动；白名单优先） |
| 未匹配 | 未匹配 | 无 | **开启（ON）** | **前台新标签页**（按全局焦点开关前台打开） |
| 未匹配 | 未匹配 | 无 | **关闭（OFF）** | **后台新标签页**（按全局焦点开关后台静默打开，默认） |

## 故障排除与常见问题解答（FAQ）

### 1. 点击链接没有在新标签页中打开
- **检查扩展主开关：** 请确认弹窗右上角或选项页中的主开关处于“开启”状态。若主开关暂停，状态徽章会显示“已暂停”，所有链接按浏览器默认方式打开。
- **浏览器受保护特殊页面：** 出于安全限制，Chrome 严格禁止任何扩展在特权页面（如 `chrome://`、`chrome-extension://`、`edge://`、`about:blank`、Chrome 应用商店及开发者工具 DevTools 页面）中注入脚本。在这些页面中点击链接遵从原生行为。
- **当前网站是否在完整跳过列表中：** 检查当前域名是否已被加入完整跳过列表。在跳过的网站上，MaiTab 会彻底卸载事件监听器，让浏览器处理所有点击。
- **页内锚点跳转链接：** 格式如 `<a href="#section">` 的页内锚点链接会被 MaiTab 智能识别并忽略，保证页内平滑滚动定位，避免误开空白新标签页。
- **使用了修饰键或非左键点击：** 若按住了 `Ctrl`、`Cmd`、`Shift` 或 `Alt` 键，或者使用的是鼠标右键、中键滚轮点击，Chrome 原生快捷机制会接管处理。
- **按钮与表单控件交互：** 网页中的 `<button>`、`<input>`、`<select>` 下拉菜单、`contenteditable` 编辑框以及带 `download` 属性的下载链接不会被当作普通超链接拦截。
- **鼠标划选文本拖拽：** 若在超链接文本内部通过按住鼠标拖拽选中文本，MaiTab 会自动判定为复制操作并阻止触发开新标签页。

### 2. 标签页总是在后台打开，不自动切换到前台（或反之）
- **核对四级优先级配置：**
  1. 若该网站已加入**自动切换白名单**，其**独立自动聚焦选项**会严格覆盖全局开关。请检查白名单中该网站是设为“聚焦”（前台打开）还是“后台”（静默打开）。
  2. 若该网站**未在白名单中**，请检查弹窗或高级设置中的**全局焦点开关**。关闭（默认）时在后台静默打开，开启时新标签页会立即获得焦点。
- **使用交互式测试器排查：** 前往高级选项页面，将目标 URL 粘贴到**交互式域名匹配测试器**中，即可直观查看其命中的具体规则及前后台行为。

### 3. 弹窗内检查更新提示“更新失败”（Update Failed）
- **GitHub 接口网络连通性与频次限制：** 检查远程更新依赖于访问公开的 GitHub REST API（`https://api.github.com/repos/Melony-mai/MaiTab`）。请确认网络连通正常。未携带 token 的未鉴权请求受到 GitHub 的 IP 限频策略约束（每小时 60 次）。
- **本地同步服务是否启动：** 弹窗内一键更新需要本地同步桥接服务处于运行状态（执行 `npm run sync:server` 或检查 `systemctl --user status maitab-sync.service`）。若本地服务未运行，可随时在终端中直接运行 `npm run sync` 进行同步。

### 4. 同步更新时检测到 Git 冲突
- **本地工作树完好保护：** MaiTab 在拉取更新前会自动通过 Git stash 保护工作区已修改文件与未跟踪文件，绝对不会静默覆盖或丢弃您的本地代码。
- **手动解决冲突流程：** 若本地已有提交与远程最新提交存在代码冲突，同步会安全暂停：
  1. 打开错误提示中列出的冲突文件。
  2. 查看并解决标准冲突标记（`<<<<<<<`、`=======`、`>>>>>>>`）。
  3. 标记已解决文件：`git add <冲突文件名>`。
  4. 继续完成变基流程：`git rebase --continue`。
  5. 如需彻底放弃本次更新并回到同步前状态，可执行：`git rebase --abort`。

### 5. 在 Chrome 中加载扩展失败（“加载已解压的扩展程序”报错）
- **开启开发者模式：** 请务必确认 `chrome://extensions/` 页面右上角的“开发者模式”处于开启状态。
- **选对根目录：** 在文件选择框中，务必选择包含 `manifest.json` 的项目根目录，不要误选 `popup` 或 `content` 等子目录。
- **文件读取权限：** 确认当前操作系统用户对项目目录具有完整的读取权限。

### 6. 界面主题没有跟随系统深浅色外观变化
- **排查手动模式覆盖：** 若此前手动点击过弹窗顶部的明暗切换按钮或在选项页中选定了“明亮模式”或“暗色模式”，手动偏好会被优先锁定。如需恢复自动跟随系统，请在弹窗设置或高级选项页的外观主题下拉菜单中选择**“跟随系统”**。

## 手动检查更新与弹窗同步

MaiTab 内置了与 GitHub 远程仓库深度集成的更新检查与同步链路，直接集成在弹窗界面中，便于在日常开发与使用中随时获取最新功能。

### 如何检查更新
1. 点击 Chrome 工具栏上的 MaiTab 图标打开扩展弹窗。
2. 在顶栏版本号（`v1.5`）旁，点击**“检查”**按钮。
3. MaiTab 将自动联络远程 GitHub 仓库（`main` 分支）与本地状态进行比对。
4. 同步状态卡片将即时展示结果：
   - **已是最新（Up to Date）：** 本地代码与 GitHub 远程最新提交完全一致。
   - **有可用更新（Update Available）：** 发现了远程新提交，卡片上将显示可用提交数量及提交标题摘要列表。
   - **检查中（Checking）：** 正在连接 GitHub API 与本地服务。
   - **更新失败（Update Failed）：** 显示具体错误原因诊断（如网络超时、接口限流或冲突）。

### 如何执行同步更新
1. 当检测到可用更新时，直接点击弹窗卡片上的**“立即更新”**（Update & Sync）按钮。
2. 同步系统会在本地原地安全处理整个更新流程：
   - **安全暂存保护：** 自动通过 Git stash 暂存当前未提交的所有代码变动与未跟踪文件，杜绝代码丢失。
   - **就地拉取集成：** 自动抓取远程提交并通过快进或变基合并到本地，无需重新克隆。
   - **自动还原改动：** 同步成功后自动还原此前暂存的本地修改。
   - **完整性自动化校验：** 同步后自动运行全套测试套件确保扩展功能完好。
3. 更新完成后，弹窗状态自动刷新为**“已是最新”**。
4. **全程零手工命令行操作：** 无需手动敲击终端命令或运行脚本，一键点击即可完成更新。

### 安全的冲突保护
若本地已提交的代码与远程提交发生冲突：
- 同步流程会安全暂停并保护当前代码。
- 明确列出冲突文件列表与排查修复指引。
- 暂存内容在 `git stash list` 中完好保留。
- 绝不会发生静默覆盖文件的行为。

## 从 GitHub 仓库直接迭代与 CLI 脚本

MaiTab 提供了功能完备的自动化代码迭代与同步工具，支持直接同步远程 GitHub 仓库的最新提交，并在此基础上持续开展二次开发，无需反复克隆或重新下载。

### 1. 运行同步迭代
在项目根目录下执行以下命令即可与远程最新版本同步：

```bash
npm run sync
# 或者
npm run iterate
```

该自动化工作流将依次执行：
1. **暂存保护未提交工作：** 自动检查工作区修改、暂存区文件及未跟踪的新文件，在执行任何同步前通过 Git stash 严密保护。
2. **抓取远程提交：** 联络 GitHub 远程仓库（`origin`）拉取最新分支状态，比对超前/落后提交数（ahead / behind）。
3. **原地应用更新：**
   - 若本地无多余未推送提交（`aheadCount === 0`），执行原子级快进合并（`git merge --ff-only`）。
   - 若本地存在未推送的新提交，自动将本地提交平滑变基（`git rebase`）到最新的远程提交之上。
4. **检测并诊断合并冲突：** 智能感知 merge、rebase 以及 stash pop 过程中的代码冲突，展示带有冲突文件路径与解决命令的详细指引，避免损坏仓库。
5. **恢复工作区暂存：** 通过 `git stash pop` 干净还原此前暂存的本地未提交改动。
6. **自动化回归校验：** 同步完成后自动触发全量测试套件（`npm test`），确保核心功能零缺陷。

### 2. 检查远程状态（Dry-Run 试运行）
若仅想检查本地分支相对于远程分支的更新状态而不修改任何本地文件，可执行：

```bash
npm run sync:check
```

### 3. 高级 CLI 命令行参数
您还可以携带定制化参数直接调用底层同步脚本：

```bash
# 仅检查远程状态，不改动任何工作树文件
node scripts/sync-repo.js --check

# 同步最新代码，但跳过同步后的测试套件
node scripts/sync-repo.js --no-tests

# 在产生分歧时采用 merge 提交策略替代默认的 rebase 变基
node scripts/sync-repo.js --merge

# 若发生冲突则自动终止变基/合并，安全还原至同步前状态
node scripts/sync-repo.js --abort-on-conflict

# 输出详细帮助使用说明
node scripts/sync-repo.js --help
```

6. **重启持久化保存：** 验证设置项、白名单、跳过列表及主题偏好在模拟浏览器重启后完整保留。
7. **Manifest V3 规范合规：** 验证 schema 结构、1.5 版本号统一性、最小权限集合、图标资源及多语言字典完整性。
8. **UI 布局与自适应适配：** 基于真实无头 Chrome DevTools 协议（CDP）测试在不同视口分辨率及缩放比例（100%、125%、150%、200%）下的无横向溢出。

10. **直接迭代测试套件：** 验证远程拉取、原地快进与变基、未提交修改安全防护、冲突诊断、试运行检查及全项目版本号一致性。

## 技术规范与权限声明

- **Manifest V3 架构：** 严格遵循 Google Chrome Manifest V3 最新技术标准，基于 Service Worker 构建，安全高效。
- **最小化权限声明：**
  - `storage`：用于将用户的配置选项、语言偏好、白名单域名、完整跳过列表与主题外观跨浏览器重启可靠持久化保存。
  - `tabs`：用于在弹窗中获取当前活动标签页的域名，以及在用户点击链接时创建新标签页，并精确控制其焦点状态、相邻位置（`index`）与父子关联关系（`openerTabId`）。
