How Domain Matching & Interception Works

Complete Bypass List (Silent List):

  • Highest Priority: If a website matches an entry in the Complete Bypass List, MaiTab is completely inactive. Link clicks, tab opening, and interactive elements follow native browser and website behavior. Event listeners are detached on bypassed sites to prevent any interference. This list strictly overrides all whitelist rules and the Global Focus Toggle.

Domain Matching Rules:

  • Exact Match: example.com matches visits on example.com.
  • Subdomain Matching: example.com also automatically matches news.example.com, blog.example.com, and any deep subdomains.
  • Protection Against False Positives: example.com will never match fakeexample.com or example.com.phishing.org.

Setting Precedence & Independence:

  • Precedence: Per-website focus options in the whitelist strictly override the Global Focus Toggle. If a website is whitelisted with focus disabled, links will always open in the background even if Global Focus is enabled. If a website is whitelisted with focus enabled, links will always receive focus even if Global Focus is disabled. For non-whitelisted websites, the Global Focus Toggle applies.

Link Click Safety:

  • Modifier Keys: Standard browser shortcuts (Ctrl+Click, Shift+Click, Alt+Click, Cmd+Click) are preserved without interference.
  • Right & Middle Clicks: Only standard left-clicks are handled. Context menus and middle-clicks are left to the browser.
  • In-page Anchors: Same-page fragment links (e.g. #comments, #section2) scroll smoothly and do not open blank tabs.
  • Interactive Elements: Buttons, dropdown menus, text inputs, text selections, and download links continue functioning normally.
