# MaiTab - Google Chrome 向けスマートタブマネージャー (v1.31)

<p align="center">
  <a href="README.md">English</a> | <a href="README_zh-CN.md">简体中文</a> | <strong>日本語</strong>
</p>

---

**MaiTab** は、**Manifest V3** に完全準拠して構築された、軽量で外部依存関係ゼロの Google Chrome 拡張機能です。現在閲覧中のページを中断することなく、ウェブリンクの左クリックを検知して自動的に新しいタブで開きます。洗練された **macOS Aqua / Apple システム設定** 準拠の UI を採用し、**ライトモード**、**ダークモード**、および **OS 外観へのリアルタイム追従（システムモード）** をサポートしています。さらに、最優先で動作する **完全バイパスリスト（サイレントリスト）**、柔軟に切り替え可能な **グローバルフォーカス設定**、サブドメイン自動判定と個別フォーカス設定に対応した **自動切り替えホワイトリスト**、**GitHub リポジトリ直接イテレーションおよびポップアップ内ワンクリック同期**、そして **英語・簡体字中国語・日本語** に対応した完全な国際化（i18n）を備えています。

## v1.31 の新機能・変更点

- **公開 GitHub リポジトリとオープンアクセス：**
  - プロジェクトのリポジトリは GitHub 上で完全公開されています：[https://github.com/Melony-mai/MaiTab](https://github.com/Melony-mai/MaiTab)。誰でも最新コードの確認や共同作業が可能です。
- **手動アップデート確認とポップアップ内ワンクリック同期：**
  - **アクセスしやすい「確認」ボタン：** ポップアップヘッダーの拡張機能バージョンバッジ（`v1.31`）のすぐ横に配置され、ワンクリックで更新チェックを実行できます。
  - **リアルタイムな同期ステータス表示：**
    - **最新です（Up to Date）：** ローカルプロジェクトがリモートリポジトリ（`origin/main`）と完全に同期しています。
    - **更新あり（Update Available）：** リモートにある新しいコミット数と、各コミットの概要タイトル・短縮ハッシュ一覧を表示します。
    - **確認中（Checking）：** GitHub API およびローカルサービスへ接続確認中であることを示すインジケーターを表示します。
    - **更新失敗（Update Failed）：** ネットワークエラーや競合発生時に、詳細な診断と原因を表示します。
  - **ワンクリック同期：** アップデートが検出された際、ポップアップ内の「今すぐ更新」ボタンを押すだけでその場で直接更新を完了でき、ターミナルでコマンドをコピー＆ペーストする必要がありません。
  - **バックグラウンドサービスとの自動連携：** ローカル同期サービス（`maitab-sync.service` / `scripts/sync-server.js`）と自動通信し、リモートの最新コミットをローカルプロジェクトへ安全に取り込みます。
  - **作業中の変更を安全に保護：** 同期処理中、未コミットの変更や未追跡ファイルを Git stash により自動退避し、マージ後に自動復元するため作業内容が失われません。
  - **競合の安全な検出と診断：** マージやリベースの競合を安全に検知し、競合ファイルを明示して解決手順を案内します。ファイルを勝手に上書きしたり Git 状態を壊すことはありません。
- **OS 外観に連動するシステムテーマ自動切り替え：**
  - **「システム」テーマオプションの追加：** ポップアップおよびオプションページの外観設定に、ライトモード・ダークモードと並んで「システム」を追加しました。
  - **OS の外観変更をリアルタイム検知：** `prefers-color-scheme` を監視し、OS のダーク/ライトテーマ切り替えに即時連動します。拡張機能やブラウザの再起動は不要です。
  - **手動選択の厳格な保持：** ユーザーが手動でライトまたはダークモードを選択した場合はその設定が固定され、再び「システム」を選択するまで維持されます。
  - **画面間の一貫性：** ポップアップと高度な設定ページの間で外観テーマと設定状態が完全に同期します。
- **ポップアップ UI レイアウトの最適化：**
  - 更新確認機能やテーマ選択を追加しながらも、余白・コンポーネント配置・視覚的階層を再調整し、横スクロールの発生や表示崩れのないスマートなレイアウトを実現しました。
- **GitHub リポジトリからの直接イテレーション機能：**
  - **その場でのコードベース更新：** 再クローンや手動ダウンロードを行うことなく、リモート GitHub リポジトリから最新コミットを取得して直接同期できます。
  - **未コミット変更の安全な自動退避：** 作業中の変更（ステージ済み・未ステージ・未追跡ファイル）を自動検知し、Git stash で一時保護します。
  - **競合の検出と分かりやすい診断出力：** マージ、リベース、stash 復元時の競合を検知し、ステップバイステップの解決コマンドを案内します。
  - **非破壊ステータス確認：** 新設の `npm run sync:check`（または `--check` / `--dry-run`）により、作業ファイルを一切変更せずにリモートとの差分状況を確認できます。
  - **同期後の自動機能検証：** 同期完了後に自動で全テスト（`npm test`）を実行し、拡張機能の正常動作とリグレッションのないことを保証します。
  - **柔軟な CLI オプション：** `npm run sync`、`npm run iterate`、`npm run sync:check`、`npm run sync:server` に対応し、`--check`、`--merge`、`--no-tests`、`--abort-on-conflict` などのフラグをサポートしました。
- **プロジェクトバージョンを v1.31 に統一：**
  - `manifest.json`、`package.json`、多言語リソース（`en`、`zh-CN`、`ja`）、UI バッジ、エクスポートデータ、自動テストスイート全域でバージョンを **v1.31** に更新しました。

## 主な機能

1. **完全バイパスリスト（サイレントリスト / Complete Bypass List）**
   - MaiTab の機能を**完全に無効化**したい特定のウェブサイトを指定できます。
   - **絶対的な最優先順位：** 完全バイパスリストは他のすべての拡張機能設定に優先します。訪問中のウェブサイトがこのリストに一致する場合、全体フォーカス設定やホワイトリストの設定に関わらず、拡張機能はリンクの動作に一切干渉しません。
   - **ブラウザ本来の挙動を維持：** 対象サイト上のすべてのリンクや対話型要素は、拡張機能がインストールされていない場合と全く同様に、通常の Chrome ネイティブ動作（同一タブ遷移、SPA ルーティング、サイト指定の `target="_blank"` など）に従います。
   - **完全な干渉ゼロとイベントリスナーの自動解除：** バイパスされたウェブサイトでは、マウスイベントリスナー（`mousedown`、`mousemove`、`mouseup`、`click`）を完全に解除し、パフォーマンス負荷や意図しない動作干渉を完全に防ぎます。
   - **独立した管理：** 通常のホワイトリストとは独立して管理され、ポップアップおよびオプションページで専用の追加・削除コントロールを備えています。
   - **サブドメイン自動判定と永続化：** `chrome.storage.sync`（ローカルフォールバック付き）により確実に保存され、サブドメインも自動的に対象となります（例: `google.com` をバイパスすると `mail.google.com` や `docs.google.com` も自動的にバイパスされます）。

2. **左クリックしたリンクをデフォルトで新規タブで開く**
   - 有効なウェブサイト上でリンクを左クリックすると、閲覧中のページを維持したまま、自動的にリンク先が新しいタブで開かれます。
   - マウスホイールの中クリックと同様の動作を左クリックで再現し、ニュース、SNS、技術ドキュメント、検索結果などを快適に読み進めることができます。
   - 元のタブ情報（`openerTabId`）を保持し、現在のタブのすぐ右隣（`index: activeIndex + 1`）に新しいタブを配置するため、新しいタブを閉じたときにスムーズに元のページへ戻ることができます。
   - 通常のナビゲーション以外の操作をインテリジェントに除外：
     - 修飾キー（`Ctrl`、`Cmd`、`Shift`、`Alt`）が押されている場合は、ブラウザ標準のショートカット機能が優先されます。
     - 右クリックや中クリックはブラウザネイティブの動作に任されます。
     - ページ内アンカーリンク（`href="#comments"` など）は同一ページ内でスムーズにスクロールし、余計なタブは開きません。
     - フォーム要素（`<button>`、`<input>`、`<textarea>`、`<select>`）、編集可能要素（`contenteditable`）、`download` 属性付きリンクは通常通り機能します。
     - リンク内のテキストをマウスドラッグで範囲選択している際は、誤って新規タブが開かないよう防止します。

3. **グローバルフォーカス設定（全体自動切り替え）**
   - リスト未登録のウェブサイトでリンクをクリックした際、新しく開いたタブに自動でフォーカスを移すかどうかを一元管理します。
   - **有効（ON）：** リンクをクリックすると新しいタブが開き、直ちにそのタブがアクティブになります（フォアグラウンド）。
   - **無効（OFF、デフォルト）：** リンクはバックグラウンドの新しいタブで静かに開き、現在の閲覧セッションが中断されません。
   - ポップアップおよびオプションページで直感的に切り替え可能です。
   - `chrome.storage.sync`（ローカルフォールバック付き）により永続化されます。

4. **サイト別独立フォーカス対応ホワイトリスト**
   - ホワイトリストに登録されたウェブサイトごとに、**個別の自動フォーカス設定**を保持できます。
   - **全体設定からの完全な独立性：** サイト別の設定はグローバルフォーカス設定よりも優先され、ドメインごとのきめ細やかなカスタマイズが可能です。
     - **フォーカス有効（フォアグラウンド）：** グローバル設定が OFF であっても、そのサイトではリンクを開いた瞬間に新しいタブへ切り替わります。
     - **フォーカス無効（バックグラウンド）：** グローバル設定が ON であっても、そのサイトではリンクが背面の新規タブで静かに開きます。
   - **サブドメイン自動照合：** `example.com` を追加すると、`news.example.com` や `sub.example.com` も自動的に対象となります。一方で `fakeexample.com` や `example.com.evil.org` などの誤判定は確実に排除します。
   - **即時反映と保存：** 設定変更はリロード不要で直ちに適用され、ブラウザを再起動しても保持されます。
   - **ワンクリック追加とポップアップ内連動：** ポップアップは現在のタブのドメインを自動判定し、「+ ホワイトリスト」ボタンとインラインのフォーカス切り替えスイッチを提供します。

5. **完全な多言語対応（i18n）**
   - **英語（en）**、**簡体字中国語（zh-CN）**、**日本語（ja）** に完全対応しています。
   - ポップアップ、オプションページ、各種ボタン、バッジ、説明文、ツールチップ、エラーメッセージ、確認ダイアログ、トースト通知に至るまですべて翻訳されています。
   - ポップアップおよびオプションページ内の言語セレクターから、再読み込みなしで即時に言語を切り替え可能です。
   - Chrome 拡張機能 MV3 の多言語標準規格（`_locales/en`、`_locales/zh_CN`、`_locales/ja`）に準拠しています。

6. **インタラクティブなドメイン照合テスターとインポート/エクスポート**
   - オプションページにはインタラクティブなテスターが搭載されており、任意の URL やドメインを入力することで、現在の設定下でどのように判定されるか（バイパス、ホワイトリスト、一般サイト）と最終的なタブ動作を即座にシミュレーションできます。
   - ホワイトリストおよび完全バイパスリストを JSON 形式で簡単にエクスポートおよびインポートでき、バックアップや端末間の移行が容易です。

7. **手動アップデート確認とポップアップ同期**
   - **アクセスしやすい確認ボタン：** ポップアップヘッダーのバージョンバッジ横に配置されています。
   - **正確なステータス判定：** ローカルコミットと GitHub リモートリポジトリを照合し、「最新です」「更新あり」「確認中」「更新失敗」を分かりやすく表示します。
   - **未コミット変更の安全な保護：** 作業中の変更や未追跡ファイルを自動退避（Git stash）し、競合発生時も安全に一時停止して解決手順を案内します。
   - **ポップアップ内ワンクリック同期：** アップデートがある場合、ボタンを押すだけでその場で直接同期を完了できます。

8. **OS 外観に自動追従するライトモード＆ダークモード**
   - **3つのモード：** **システム（自動追従）**、**ライトモード**、**ダークモード** をサポートしています。
   - **OS とのリアルタイム同期：** システムモードでは、OS のテーマ変更（`prefers-color-scheme`）をリアルタイムに検知して即座に画面全体へ反映します。
   - **手動設定の優先：** 手動でライトまたはダークモードを選択した場合はその設定が固定され、再びシステムモードを選択するまで維持されます。
   - **UI 全体の一貫性：** ポップアップとオプションページの間で統一されたテーマが適用されます。

## 動作決定マトリクスと設定優先順位

MaiTab は、以下の厳格で分かりやすい 4 段階の優先順位に従ってリンククリック時の動作を決定します：

```text
[ 第 1 段階：拡張機能の全体マスター切り替え ]
                      │
            拡張機能は有効ですか？
             ├── いいえ ──> ブラウザ通常のリンク遷移（拡張機能は一時停止）
             └── はい
                  │
[ 第 2 段階：完全バイパスリスト（サイレントリスト） ]
                  │
         訪問先サイトはバイパスリストに該当しますか？
          ├── はい   ──> ブラウザ標準のネイティブ動作（拡張機能は完全停止・リスナー解除）
          └── いいえ
               │
[ 第 3 段階：サイト別ホワイトリスト設定の上書き ]
               │
      訪問先サイトはホワイトリストに登録されていますか？
       ├── はい   ──> サイト別の個別フォーカス設定を適用（全体設定を上書き）
       │               ├── フォーカス ON  ──> フォアグラウンドの新規タブ（タブをアクティブ化）
       │               └── フォーカス OFF ──> バックグラウンドの新規タブ（現在のページを維持）
       └── いいえ
            │
[ 第 4 段階：グローバルフォーカス設定 ]
            ├── ON  ──> フォアグラウンドの新規タブ（タブをアクティブ化）
            └── OFF ──> バックグラウンドの新規タブ（現在のページを維持、デフォルト）
```

### 優先順位決定テーブル

| 完全バイパスリスト一致 | ホワイトリスト一致 | サイト別フォーカス設定 | グローバルフォーカス設定 | 最終的なリンク・タブ動作 |
| :---: | :---: | :---: | :---: | :--- |
| **一致** | 任意 | 任意 | 任意 | **ブラウザネイティブ動作（拡張機能は完全に何もしない）** |
| 不一致 | **一致** | **フォーカス ON** | 任意（ON / OFF） | **フォアグラウンド新規タブ**（直ちにフォーカス；ホワイトリスト優先） |
| 不一致 | **一致** | **フォーカス OFF** | 任意（ON / OFF） | **バックグラウンド新規タブ**（現在のタブを維持；ホワイトリスト優先） |
| 不一致 | 不一致 | なし | **ON** | **フォアグラウンド新規タブ**（全体設定 ON に従う） |
| 不一致 | 不一致 | なし | **OFF** | **バックグラウンド新規タブ**（全体設定 OFF に従う、デフォルト） |

- **リスト切り替えタブ：**
  - **ホワイトリストタブ：** 登録済みドメインの確認、個別自動フォーカス設定の切り替え、新規ルールの追加を行えます。
  - **完全バイパスタブ：** MaiTab を完全に無効化するドメインの確認、追加、削除を行えます。

## トラブルシューティングとよくある質問（FAQ）

### 1. リンクをクリックしても新しいタブで開かない
- **マスター切り替えの確認：** ポップアップ右上またはオプションページのマスター切り替えスイッチが「ON」になっているか確認してください。一時停止中の場合、バッジは「一時停止」となり、通常のブラウザ遷移が行われます。
- **ブラウザの内部・特殊保護ページ：** セキュリティ上の制限により、Chrome は `chrome://`、`chrome-extension://`、`edge://`、`about:blank`、Chrome ウェブストア、DevTools ページなどの特権ページへの拡張機能スクリプトの挿入を禁止しています。これらのページではブラウザ標準の動作となります。
- **完全バイパスリスト（サイレントリスト）の確認：** 該当サイトが完全バイパスリストに登録されていないか確認してください。バイパスされたサイトでは、MaiTab はイベントリスナーを完全に解除し、ブラウザ本来の挙動を維持します。
- **ページ内アンカーリンク：** `<a href="#section">` のような同一ページ内のアンカーリンクは、滑らかなページ内スクロールを保ち不要なタブを開かないよう、意図的に MaiTab の処理対象外としています。
- **修飾キーやクリック種別の確認：** `Ctrl`、`Cmd`、`Shift`、`Alt` キーを押しながらのクリックや、右クリック・中クリックを行った場合は、Chrome 本来のショートカット処理が優先されます。
- **ボタンや入力欄などの対話要素：** `<button>`、`<input>`、`<select>` ドロップダウン、`contenteditable` 編集領域、および `download` 属性付きリンクは通常通り機能するよう保護されています。
- **テキストのドラッグ選択：** リンク内のテキストをマウスドラッグで範囲選択している際は、誤操作を防ぐために新規タブオープンを抑止します。

### 2. タブがフォアグラウンドに切り替わらずバックグラウンドで開く（またはその逆）
- **優先順位設定の確認：**
  1. 該当サイトが**ホワイトリストに登録されている場合**、その**サイト別フォーカス設定**がグローバル設定よりも優先されます。ホワイトリストタブまたはオプションページで該当サイトの設定（「フォーカス」または「背景」）を確認してください。
  2. 該当サイトが**ホワイトリスト未登録の場合**、ポップアップまたはオプションの**グローバルフォーカス設定**を確認してください。OFF（デフォルト）の場合は背面の新規タブで静かに開き、ON の場合は新しいタブが直ちにフォーカスされます。
- **ドメイン照合テスターの活用：** オプションページの「インタラクティブなドメイン照合テスター」に該当 URL を入力することで、適用されるルールとタブ動作をリアルタイムで確認できます。

### 3. ポップアップで更新確認時に「更新失敗」（Update Failed）と表示される
- **GitHub API 接続とレートリミット：** 更新確認は公開されている GitHub REST API（`https://api.github.com/repos/Melony-mai/MaiTab`）へアクセスします。インターネット接続が有効であることを確認してください。認証なしのリクエストには GitHub の IP ごとの利用制限（60回/時）が適用されます。
- **ローカル同期サービスの状態：** ポップアップからのワンクリック同期を行うには、ローカル同期ブリッジが稼働している必要があります（`npm run sync:server` または `systemctl --user status maitab-sync.service`）。サーバーが停止している場合でも、ターミナルから直接 `npm run sync` を実行して更新可能です。

### 4. 同期中に Git の競合（コンフリクト）が検出された
- **ローカル作業の確実な保護：** MaiTab は更新を取得する前に、未コミットの変更や未追跡ファイルを Git stash で自動退避するため、コードが勝手に消去されることはありません。
- **競合の解決手順：** ローカルコミットとリモートコミットに競合がある場合、処理は安全に一時停止します：
  1. エラーメッセージに表示された競合ファイルを開きます。
  2. 標準の競合マーカー（`<<<<<<<`、`=======`、`>>>>>>>`）を確認して編集・解決します。
  3. 解決したファイルをステージングに追加します：`git add <対象ファイル>`。
  4. リベースを続行します：`git rebase --continue`。
  5. 今回の更新を完全に中止して同期前の状態に戻したい場合は、次を実行します：`git rebase --abort`。

### 5. Chrome への読み込みに失敗する（「パッケージ化されていない拡張機能の読み込み」エラー）
- **デベロッパーモードの確認：** `chrome://extensions/` 画面右上の「デベロッパーモード」が ON になっていることを確認してください。
- **選択ディレクトリの確認：** `manifest.json` が存在するプロジェクトのルートフォルダを選択してください（`popup` や `content` などのサブフォルダを選択しないでください）。
- **アクセス権限：** 選択したフォルダおよびファイルに対して、お使いのユーザーアカウントに読み取り権限があることを確認してください。

### 6. 外観が OS の深浅テーマに追従しない
- **手動モード優先の解除：** 過去にポップアップ上部のアイコンで手動切り替えを行ったり、オプションで「ライトモード」や「ダークモード」を明示的に選択した場合、その手動設定が優先的に保持されます。再び OS に自動追従させたい場合は、テーマ設定のドロップダウンで**「システム」**を選択してください。

## 手動アップデート確認とポップアップ同期

MaiTab は、日常的な開発とリモート GitHub リポジトリとのリアルタイムな同期を円滑に行えるよう、ポップアップ画面内にアップデート確認と同期ワークフローを統合しています。

### アップデートの確認方法
1. Chrome ツールバーの MaiTab アイコンをクリックしてポップアップを開きます。
2. ヘッダーのバージョンバッジ（`v1.31`）横にある**「確認」**ボタンをクリックします。
3. リモート GitHub リポジトリ（`main` ブランチ）とローカル状態が照合されます。
4. 同期カードに現在の状況が表示されます：
   - **最新です（Up to Date）：** ローカルプロジェクトは GitHub リモートの最新コミットと一致しています。
   - **更新あり（Update Available）：** 新しいリモートコミットが見つかりました。コミット件数と概要タイトル一覧が表示されます。
   - **確認中（Checking）：** GitHub API およびローカルサービスへ接続確認中です。
   - **更新失敗（Update Failed）：** エラーの詳細（ネットワーク接続、API 制限、競合など）が表示されます。

### 同期・更新の実行方法
1. 更新が利用可能な場合、ポップアップ内の**「今すぐ更新」**（Update & Sync）ボタンをクリックします。
2. 同期システムがその場で安全に更新を処理します：
   - **安全な一時退避：** ローカルの未コミット変更や未追跡ファイルを Git stash により自動退避します。
   - **その場での統合：** 再クローンすることなく、リモートコミットを自動取得してファストフォワードまたはリベースで統合します。
   - **自動復元：** 退避していたローカルの変更を自動で作業ディレクトリへ復元します。
   - **完全性検証：** 同期完了後に自動テストを実行し、機能が正常であることを確認します。
3. 完了すると、ポップアップのステータスは自動的に**「最新です」**に更新されます。
4. **手動コマンド不要：** ターミナル操作やスクリプト実行を行うことなく、画面上のクリックだけで更新が完了します。

### 安全な競合処理
ローカルの変更とリモートのコミットに重複や衝突がある場合：
- 同期は安全に一時停止し、現在の作業を保護します。
- 競合しているファイルの一覧と具体的な解決コマンドが案内されます。
- 退避された変更は `git stash list` 内に安全に保持されます。
- ファイルが勝手に上書きされることは一切ありません。

## GitHub リポジトリからの直接イテレーションと CLI スクリプト

MaiTab は、リモート GitHub リポジトリから最新の変更を安全に同期し、再クローンすることなく更新されたコードベースをそのまま次の開発の起点として利用できるイテレーション機能を備えています。

### 1. 同期とイテレーションの実行
リモートの最新バージョンと同期するには、プロジェクトルートで以下を実行します：

```bash
npm run sync
# または
npm run iterate
```

この自動化ワークフローは以下を順次実行します：
1. **未コミット作業の保護：** 作業ディレクトリ内の変更、ステージングされたファイル、未追跡ファイルを自動検出し、Git stash により一時保護します。
2. **リモート更新の取得：** GitHub（`origin`）から最新コミットを取得し、進み/遅れ（ahead / behind）を判定します。
3. **その場での更新適用：**
   - 未プッシュのローカルコミットがない場合（`aheadCount === 0`）、アトミックなファストフォワードマージ（`git merge --ff-only`）を適用します。
   - ローカルに未プッシュのコミットがある場合、最新のリモートコミットの上にローカルコミットを自動でリベース（`git rebase`）します。
4. **競合の検出と診断案内：** マージ、リベース、stash 復元時の競合を検知し、ファイルパスや解決コマンドを含む親切な診断メッセージを出力します。
5. **退避した作業の復元：** `git stash pop` により、退避していた未コミットの変更を安全に作業ディレクトリへ復元します。
6. **機能整合性の検証：** 同期完了後に自動でテストスイート（`npm test`）を実行し、不具合の混入を防ぎます。

### 2. リモート状態の確認（Dry-Run チェック）
作業ツリーを変更せずに、ローカルブランチがリモートに対して進んでいるか遅れているかを確認するには以下を実行します：

```bash
npm run sync:check
```

### 3. 高度な CLI オプション
スクリプトには各種オプションフラグを指定して直接実行することも可能です：

```bash
# 作業ツリーを変更せずにリモートの状態のみ確認する
node scripts/sync-repo.js --check

# 同期後の自動テスト実行をスキップして同期する
node scripts/sync-repo.js --no-tests

# 分岐時にリベースではなくマージコミット方式を使用する
node scripts/sync-repo.js --merge

# 競合が発生した場合に自動でリベース/マージを中止し、同期前の状態に戻す
node scripts/sync-repo.js --abort-on-conflict

# 詳細なヘルプを表示する
node scripts/sync-repo.js --help
```

## 自動テストと検証

MaiTab には、Node.js 組み込みのテストランナーを使用して実行される包括的な自動テストスイートが付属しています。

全テストを実行するには：

```bash
npm test
```

テストスイートは以下の項目を網羅的に検証します：
1. **ライト・ダーク・システムテーマ対応：** スイッチの対話性、DOM スタイルの即時適用、再起動後の永続化、および各テーマにおける視覚要素の正常性。
2. **完全バイパスリスト（サイレントリスト）：** バイパスリストに登録されたサイトでリンクが通常のブラウザ挙動に従い、イベントリスナーが完全に解除されること。
3. **ホワイトリストのフォーカス動作：** ホワイトリストに登録されたサイトで、設定された自動フォーカス（フォアグラウンド/バックグラウンド）が正確に動作すること。
4. **全体設定へのフォールバック：** いずれのリストにも含まれない一般サイトがグローバル設定に従うこと。
5. **優先順位の階層構造：** 同一ドメインがバイパスリストとホワイトリストの両方に一致する場合、完全バイパスリストが最優先されること。
6. **再起動後の設定永続化：** 設定、ホワイトリスト、バイパスリスト、テーマ設定がブラウザ再起動のシミュレーション後も保持されること。
7. **Manifest V3 構造の妥当性：** スキーマ適合性、バージョン 1.31 の統一性、パーミッション、アイコンファイル、多言語リソースの完全性。
8. **UI レイアウトとレスポンシブ適応：** 実際のヘッドレス Chrome DevTools プロトコル（CDP）を使用し、多様なビューポート幅および画面拡大率（100%、125%、150%、200%）での横スクロールなしのレイアウト維持を検証。
9. **GitHub リポジトリ同期：** 安全な退避、取得、リベース、および変更復元ワークフローの動作。
10. **直接イテレーションスイート：** リモートフェッチ、ファストフォワード、リベース、作業中の変更保護、競合検出と診断、ドライラン確認、全プロジェクトのバージョン整合性。

## 技術仕様とパーミッション

- **Manifest V3 準拠：** Google Chrome の最新 Manifest V3 仕様に厳格に準拠し、Service Worker ベースで効率的に動作します。
- **必要最小限のパーミッション：**
  - `storage`：ユーザー設定、言語選択、ホワイトリスト、完全バイパスリスト、および外観テーマをブラウザ再起動をまたいで確実に保存するために必要です。
  - `tabs`：ポップアップで現在のタブのホスト名を取得し、リンククリック時に新しいタブを適切なフォーカス状態、位置（`index`）、および元のタブとの親子関係（`openerTabId`）を指定して生成するために必要です。
- **外部依存関係ゼロ：** 外部フレームワークや CDN、サードパーティ製ライブラリを一切含まず、プライバシーを侵害するアクセス解析や追跡コードも存在しません。
